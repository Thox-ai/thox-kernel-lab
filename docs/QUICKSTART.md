# thox-kernel-lab — Quickstart

There is nothing to build or run in v0.1.0 — this release is the
specification set. The five-minute path:

```sh
git clone https://github.com/Thox-ai/thox-kernel-lab.git
cd thox-kernel-lab
```

Then read, in order:

1. `README.md` — scope and honest status.
2. `CLEAN_ROOM_CHARTER.md` — the provenance rules.
3. `specs/SPEC-INDEX.md` — specifications S1–S9.

Implementation crates arrive in later releases under the Charter's
specification-first order.
